How RapidCare Works

🚨 Step 1: Emergency Trigger

User presses SOS or logs in to request help.

📍 Step 2: Location Detection

System uses GPS to detect your real-time location.

🏥 Step 3: Hospital Matching

Nearby hospitals are fetched using OpenStreetMap APIs.

🚑 Step 4: Ambulance Booking

User selects ambulance based on ETA, type, and rating.

🗺️ Step 5: Live Tracking

Ambulance is tracked in real-time using maps.

🏁 Step 6: Hospital Arrival

Patient reaches hospital safely and request is completed.
